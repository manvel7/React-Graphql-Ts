

A Next.js + TypeScript + GraphQL project that integrates with the Twitch API to explore live streams, channels, and categories. Built with a modern frontend stack, this app focuses on performance, type safety, and a seamless user experience.

✨ Features

🔴 Live Stream Feed – Browse trending and top live streams.

🎮 Game & Category Search – Discover streams by game or category.

👤 Streamer Profiles – View channel details, followers, and live status.

💅 Responsive UI – Optimised for both desktop and mobile.

⚡ GraphQL Queries – Efficient data fetching with strong typing.

🛠️ TypeScript-first – End-to-end type safety and maintainability.

🛠️ Tech Stack

Framework: Next.js

Language: TypeScript

Data Layer: GraphQL (Apollo Client / urql)

Styling: Tailwind CSS / styled-components (your choice)
